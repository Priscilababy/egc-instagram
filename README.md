# egc-instagram

Posteos diarios de Instagram de **EGC · Electric Global Cost** (@egc_eletric_global_cost).

Una rutina de Claude corre todos los días a las 19:00. Arma la placa del día siguiente, la guarda en `posts/` y la programa en Metricool para las 10:00.

- `CLAUDE.md` · instrucciones completas que sigue la rutina.
- `temas.md` · lista de temas pendientes. Editala para cambiar el orden o agregar temas.
- `publicados.md` · registro de lo publicado.
- `generador/` · biblioteca de diseño de las placas, logo y fuentes.
- `posts/` · imágenes y textos de cada día.

Para frenar la automatización: pausá la rutina en claude.ai/code/routines.
Para frenar un posteo puntual: borralo o editalo en el planificador de Metricool antes de las 10:00.
